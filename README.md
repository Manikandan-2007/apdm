# APDM (Anbu Pathivu Ninaivugal)

Cherished Voices, Timeless Memories — An empathetic, voice-first remembrance companion web application rewritten in React, TypeScript, Vite, and Tailwind CSS.

## Overview

APDM is designed to honor and preserve beloved family memories, traditions, stories, and words of encouragement. It enables reflections across Tamil, Tanglish, and English with voice and conversational interactions.

## Features

- **Empathetic AI Reflection**: Powered by Google Gemini with an offline-capable high-fidelity fallback engine with contextual memory retrieval.
- **Multilingual Support**: Real-time language detection and response generation for Tamil, Tanglish, and English.
- **Voice-First Experience**: Web Speech API integration with voice-to-text recognition, spoken audio playback, and pulsing concentric voice orb visualizer.
- **Preserved Memories Archive**: Categorized memories (Personal, Family, Stories, Important Events, Favourite Things, Messages) with mood tags and searchable reflections.
- **80+ Conversational Starters ("Innum paaru")**: Thematic suggestion chips and comprehensive category browser across family roles (Meenu, Dinesh, Padma, Samayal, Childhood, etc.).
- **7 Curated Ambience Themes**:
  - Midnight Amber (Maroon & Sandalwood)
  - Sacred Temple Gold (Gold & Deep Charcoal)
  - Sandalwood & Rose (Teal & Terracotta)
  - Serene Forest Sage (Olive & Leaf)
  - Royal Amethyst (Purple & Lavender)
  - True AMOLED Onyx (Pitch Black)
  - Ivory Linen (Warm Paper Daylight)
- **Memorial Profiles**: Switch perspectives between family members and loved ones while honoring memorial dignity.

## Getting Started

```bash
npm run dev
```
